Slayer is how you gear your ironman. The whip, trident, occult, zenyte shards — they all come from slayer. Here's how to do it efficiently.

**At a glance:**
- **First priority:** Get black mask at 58 slayer (16.67% damage/accuracy boost)

## Recent Slayer Updates (2024-2025)

Major changes to slayer mechanics that fundamentally alter how you approach the skill:

### Separate Block Lists Per Master

**You can now have different block lists for each slayer master.** This is massive for optimisation:
- Block metal dragons on Duradel for XP
- Block different tasks on Konar for hydra farming
- Set up Turael for efficient point boosting
- Customise Steve for inferno/fight caves tasks

**New interface:** View and block tasks without getting them first. Just click "View list" on any slayer master.

### Metal Dragons Combined Into One Task

All metal dragons (bronze, iron, steel, mithril, adamant, rune) are now **one single task** with:
- **14 weight** — Highest weight in the game
- You choose which dragons to kill
- **Must block on every master** unless specifically farming rune dragons

## Black Mask — Get This ASAP

At 58 slayer, cave horrors drop the [black mask](https://oldschool.runescape.wiki/w/Black_mask). This is your #1 priority.

**Why it matters:**
- **16.67% damage AND accuracy boost** on task
- Works immediately — no slayer points needed
- Later upgrades into the slayer helm (same boost, more slots)

<Callout type="efficiency">
The black mask boost is so significant that rushing 58 slayer should be a priority. Every task after getting it becomes noticeably faster. Don't wait.
</Callout>

**How to get it:**
- Kill cave horrors in Mos Le'Harmless (Cabin Fever quest required)
- 1/512 drop rate — expect 1-2 hours
- Bring a light source and antipoison

## Imbuing Your Slayer Helm

The slayer helm provides 16.67% melee boost on task. **Imbuing** adds 15% ranged AND magic boost — essential for bursting and ranged tasks.

### Imbue Methods (Best to Worst)

| Method | Cost | Time | Notes |
|--------|------|------|-------|
| **[Emir's Arena](https://oldschool.runescape.wiki/w/Emir%27s_Arena)** (scroll of imbuing) | 200 points | 30-40 mins | Fastest. PvP matches, but points for losing too. |
| Soul Wars | 500 zeal tokens | 2-4 hours | Team-based minigame, depends on wins |
| Nightmare Zone | 1.25M points (625k with Hard CA) | 4-8 hours | AFK but slow, costs supplies |

**Recommendation:** Emir's Arena. Even if you lose every match, you get 11-12 points. At 200 points needed, that's ~18 matches or about 30-40 minutes. No supplies needed — gear is provided.

<Callout type="tip">
The [scroll of imbuing](https://oldschool.runescape.wiki/w/Scroll_of_imbuing) is reusable if you uncharge the item. You can swap it between slayer helm and other items (berserker ring, etc.) as needed.
</Callout>

### What to Imbue First
1. **Slayer helm** — You use this constantly
2. **Berserker ring** — Doubles strength bonus (+4 → +8)
3. **Archers ring** — If doing a lot of ranged content

## Which Slayer Master to Use

The meta has changed. Here's when to use each master:

### Duradel (100 Combat, 50 Slayer) — Best for XP

**Your default master.** Duradel has:
- Highest weight on good tasks (bursting, cannoning)
- Better XP rates than Steve/Nieve
- Most efficient for 87-99 grind

**Use for:** General slayer training, XP, most efficient progression

### Konar quo Maten (75 Combat) — Milestones Only

Konar forces you to kill monsters in specific locations, which hurts XP rates significantly.

**Only use for:**
- Every 10th/50th/100th/etc task (milestone bonus points)
- Hydra farming (if you're 95+ slayer and only want hydra tasks)

**Don't use as main master** — the forced locations make tasks slower.

### Nieve/Steve (85 Combat) — TzHaar Tasks Only

Steve is now ONLY worth using for one reason:
- **Highest TzHaar weight** of any master (for fight caves/inferno tasks)

If you're not grinding Jad or Zuk, don't use Steve. Duradel is better for everything else.

### Turael (3 Combat) — Point Boosting

Lowest-level master with the fastest tasks (birds, cows, rats).

**Use for:**
1. **Point boosting:** 9 Turael tasks → 10th task with Duradel = ~100+ points/hour
2. **Task cancelling:** Call Turael to reset a bad task (resets streak)

See detailed Turael section below for block list.

### Krystilia (Wilderness) — Optional Money/Points

Assigns wilderness-only tasks. Separate task streak.

**Pros:**
- High points per task
- Larran's keys (prayer XP, seeds, runes)
- Good money (revenants)

**Cons:**
- PK risk (not for HCIM)
- Interrupts main progression

**Verdict:** Situational. Do if comfortable with PvP risk and want extra points.

## Block List Strategy

You get up to **7 block slots total** (1 per 50 quest points, max at 350 QP). Use them wisely.

### Block List Philosophy

**Golden rules:**
1. **Block HIGH weight tasks you don't want** — Costs points but saves many future skips
2. **Cancel/skip LOW weight tasks** — Cheaper than blocking, won't appear often
3. **Aim for ~0 points per task long-term** — Perfect efficiency (see tools section below)

**Task weight matters:**
- 14 weight = ~14% of all tasks (metal dragons)
- 9 weight = ~9% of all tasks
- 8 weight = ~8% of all tasks
- 2 weight = ~2% of all tasks

**Example:** Metal dragons (14 weight) appear in roughly 1 in 7 tasks. If you hate them, that's 100 points to block vs 3,000+ points spent skipping over time. Always block high-weight tasks you don't want.

## Turael Block List (Point Boosting)

If you're doing **9 Turael tasks → 10th with Duradel** for points, set up Turael's block list:

**Block (7 slots):**
1. **Lizards** — Very slow, need ice coolers or sulphur lizards
2. **Bats** — Spread apart, need long-range weapon, slow
3. **Dogs** — Few spawns, high HP, annoying
4. **Dwarves** — Slow at White Wolf Mountain
5. **Skeletons** — High HP, tedious
6. **Wolves** — High HP (though multi-combat)
7. **Kalphites** — **CRITICAL for task cancelling**

### Why Block Kalphites on Turael?

If you get kalphites from Duradel and ask Turael to cancel it, he'll say "that's my task too, complete it." But if you **block kalphites on Turael**, he "forgets" it's his task and will cancel it for you.

**This applies to any task both masters share.** Blocking on Turael lets him cancel it.

<Callout type="efficiency">
Turael boosting gets you ~100-150 points per hour early game. Stop once you have superiors, slayer helm, and 3-4 blocks. After that, normal tasks are more efficient.
</Callout>

## Optimisation Tools

### Skilling Discord Slayer Spreadsheet

The most powerful tool for customizing your block list is the **[Skilling Discord Slayer Spreadsheet](https://docs.google.com/spreadsheets/d/14-rahdjUzFiWe5STNV87GBekIc45FtXwYmH58JPUsVc/)**.

- Calculates optimal blocks based on YOUR goals

**How to use:**
1. **File → Make a Copy** (so you can edit it)
2. Toggle your settings (gear, alts, unlocks)
3. Mark tasks as "Do", "Block", "Skip", or "Don't unlock"
4. Watch the "Points per task" stat — get it close to 0
5. Use the generated block list in-game

**Example:**
- You want Kraken pet → Mark cave kraken as "Do"
- Points per task goes to +2.63 → You can block something else
- Block black dragons → Back to 0.32 points per task → Perfect

The spreadsheet shows you EXACTLY what's efficient for your situation. No guesswork.

<Callout type="tip">

## Bursting & Barraging

Dust devils (65) and nechryaels (80) should be burst/barraged in the Catacombs of Kourend.

**Why burst:**
- 200-300k+ magic XP/hr
- Great drops (herbs, seeds, runes)
- Passive prayer XP with bonecrusher

**Setup:**
- Proselyte armour (prayer bonus) + magic attack items
- Defensive casting (for defence XP)
- Bonecrusher + dragonbone necklace (prayer sustain)
- Rune pouch with blood/death/water runes

**Method:**
1. Stack monsters in a corner (run through them)
2. Cast Ice Burst/Barrage
3. Collect loot with bonecrusher handling bones
4. Repeat

<Callout type="efficiency">
Bursting dust devils and nechryaels is the best magic training in the game. Don't skip these tasks — extend them with a bracelet of slaughter.
</Callout>

## Point Boosting (Early Game Only)

**Do 9 Turael tasks → 10th task with Duradel = ~100-150 points/hour.**

See the "Turael Block List" section above for what to block. This method is only worth doing when you're starting from zero points.

**When to stop:**
- Once you have superiors (50 points)
- Slayer helm unlocked (400 points)
- 3-4 block slots filled (300-400 points)

After that, normal slaying is more efficient than boosting.

### Task Cancelling with Turael

If you get a terrible task from Duradel:
1. Call Turael (NPC Contact or teleport to Burthorpe)
2. He'll cancel your task and give you one of his
3. **This resets your task streak to 0**

Only do this for truly awful tasks. Skipping with points (30 points) is usually better.

### Expeditious & Slaughter Bracelets

- **[Expeditious bracelet](https://oldschool.runescape.wiki/w/Expeditious_bracelet)** — 25% chance to not count kill toward task (speeds up bad tasks)
- **[Bracelet of slaughter](https://oldschool.runescape.wiki/w/Bracelet_of_slaughter)** — 25% chance to not count kill toward task BUT you still get XP (extends good tasks)

Use expeditious on tasks you want done fast. Use slaughter on burst tasks (dust devils, nechryaels) to extend them.

<Callout type="tip">
These bracelets are a great use for opals and jades — gems that otherwise just pile up in your bank. Craft them at 23 and 29 Crafting respectively.
</Callout>

## FAQ

### Should I block metal dragons?

**Yes, on every master.** 14 weight means ~14% of all tasks. This is mandatory unless you specifically want to farm rune dragons for money.

### Why do I need separate block lists for each master?

Different masters have different task weightings. What's efficient for Duradel (XP focus) isn't efficient for Konar (hydra farming) or Turael (point boosting). Set up each master's blocks separately.

### Should I rush 58 slayer for the black mask?

Yes. The 16.67% damage and accuracy boost affects every task after that. It's one of the biggest upgrades you can get early and requires no slayer points — just the drop.

### When should I stop Turael boosting?

Once you have superiors (50 points), slayer helm (400 points), and 3-4 blocks (300-400 points). After ~1,200 total points spent, normal slaying is more efficient.

### Block or skip black demons?

If you still need zenyte shards from Demonic Gorillas, **skip** instead of block. Blocking permanently removes the task until you unblock. Once you have 4+ zenytes, then block.

### Is Konar worth using as a main master?

No — her forced locations hurt XP rates significantly. Only use for:
- Every 10th/50th/100th task (milestone points)
- Hydra farming if you're 95+ slayer

Otherwise, Duradel is better.

### Should I use the Skilling Discord spreadsheet?

Yes, especially if you're optimising for specific goals (pets, money, XP). It calculates the mathematically perfect block list for your situation. Link in "Optimisation Tools" section above.

### Should I cannon every task?

No. Prioritise:
1. **Burst** dust devils and nechryaels (200-300k magic XP/hour)
2. **Cannon** dagannoths, kalphites, bloodvelds when you have spare balls
3. **Melee** everything else

Bursting > Cannoning > Melee for efficiency.

## Common Mistakes

- **Not blocking metal dragons** — 14 weight means 1 in 7 tasks. Block on every master you use.
- **Not setting up separate block lists** — Each master can have different blocks now. Optimise each one.
- **Not rushing black mask** — The 16.67% boost is massive. Get 58 slayer and camp cave horrors.
- **Rushing slayer helm before superiors** — Superiors cost 50 points now and drop imbued heart. Get them first.
- **Not imbuing slayer helm via Emir's Arena** — It's 30 mins, not hours. Do it as soon as you have the helm.
- **Blocking black demons when you need zenytes** — Skip instead to keep Demonic Gorillas open.
- **Blocking hellhounds when you want Cerberus** — Skip instead until you're done with the boss.
- **Skipping burst tasks** — Dust devils and nechryaels are 200-300k magic XP/hour. Never skip these.
- **Using Steve when you can use Duradel** — Duradel is better for XP. Only use Steve for TzHaar tasks.
- **Using Konar as main master** — Forced locations kill XP rates. Use for milestones only.
